# 魔方角色範圍與組隊流程

這段由 L203–L300 的 98 個原缺失位置和 SL185–SL275 的 91 條字串重建。角色檢查採保留的六筆群對齊，包含兩次共享讀取、各自的暫存槽、條件和分支。共享寫回沿用保留的編譯樣式，先算右側，再經傳回值寫入共享鍵。逐筆檔另存推定操作與跳轉。

| 位置 | 流程 |
| --- | --- |
| L203–L212 | 清零層數、幸運怪及進圖走位，再等待。 |
| L213–L230 | 若角色開始與結束只填一端，等待後分別於 L220 或 L229 提出 `ExitScript(0)`。 |
| L231–L254 | 兩端皆非零時，把開始角色寫入待切角色鍵。兩端皆為零時，保留原待切角色值，並將角色開始設回 0。已保存的條件只檢查零值，重播也涵蓋開始大於結束。 |
| L255–L278 | 組隊值 4 改為 2，寫「只打一關」為 1；周常為 0 時改為 1。其他組隊值保留原值，「只打一關」寫 0。 |
| L279–L300 | 產生啟動與角色設定訊息，使用保留的亂數範圍產生游標移動和點擊意圖，接到 L301 的等待迴圈入口。 |

L274 推定跳到 L279，L275 對應另一分支的延遲。L269 跳過周常設定時，可經 L274 合流，也保留直接到 L279 的候選。這兩種落點之間的行為差異僅是多經一筆跳轉，原位址仍待取得。

75 組案例從前一段介面重播取得共享值，再執行這段。30 組在只填一端時停止，45 組到 L301。共 4,074 步，涵蓋 98 個推定位置，使用合成色碼與亂數回覆。角色更換、後續工作及主循環仍待銜接。

解壓開發包後，可執行 `python source/build_cube_character_setup.py`。
