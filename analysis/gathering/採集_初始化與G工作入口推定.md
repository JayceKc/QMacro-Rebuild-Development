## 父程序和工作入口

L80–L89 同屬原位置 ID 70。模組 07 的 L717–L725 保存了一個九筆的「啟動工作、父程序略過工作入口、寫回共享 ID」樣式，可對到採集 L80–L88 及 SL72–SL76。推定父程序從 L81 跳過 L82–L84，在 L85–L88 保存工作 ID。保留的 L917 確實讀取相同 ID 鍵。L89 的原作用仍不明。

L82 建立的框架類別可回查原宣告 L5，框架名稱與 L890–L914 的 G 輪詢主體相符。L83 呼叫 L890 是有來源的推定，原呼叫運算元仍缺。G 主體已有獨立副本案例，這次重播只檢查父程序的啟動及 ID 寫回，工作入口與父程序的推定關係仍待動態驗證。這段重建沒有新增介面回呼，保留的 Form1 等待與結束路徑仍在 L1622–L1625。

88 組合成案例涵蓋全部 11 個功能索引、版本相符與否及四組勾選狀態。父程序走過 79 個不同位置，並在 L78 或 L89 的未解邊界停下。視窗、檔案、外掛及輸入動作都只記錄意圖。
